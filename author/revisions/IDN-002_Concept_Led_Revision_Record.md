## Teaching decisions

The main Department incident is completed before authentication and lifecycle variants: selected directory FIN explains current identity FIN, approved preview/application supplies HR, and no configured synchronization means no directory-write conclusion. This gives the learner a complete normal mechanism before following the profile's other responsibilities.

Neutral HR/directory/account values remove biography while preserving authority, selected value source and authentication-source roles. Email is illustrative, not mailbox evidence. The lifecycle variation is explicitly separate, with enabled configuration, exact technical-name match, automatic assignment, supported authorized write and actual target check.

The evidence table now explicitly separates mapped cloudLifecycleState from actual lifecycle assignment, then from target success. Responsibility hierarchy isn't execution order. All original cases and transfer purposes remain; their counts and the diagram count aren't quotas.
