## Changes and teaching decisions

The learner begins with raw code and exact final label, follows the complete inline value chain and normal application before operation-placement, contract and reference variations. It distinguishes intermediate values, shared instructions and applied fields.

Removed the employee/number/identity/account IDs and source brand. HR-Primary and Directory-Primary are neutral source references required by provenance reasoning. Shared name HR department code replaces the earlier story-dependent name; reference attributes.id matches it exactly. Codes, prefixes, owner agreements, error limits and assessment purposes remain.

The root-first definition is read inward to find input, then outward through returned strings. Caller meaning is introduced before shared-use reasoning; the earlier contract explanation uses plain operation language. A -> B -> A illustrates an excluded cyclic dependency without inventing a runtime error or recursion algorithm.

Three complete definitions, two value/change tables and two diagrams remain because they expose inline composition and shared dependency mechanics. No quotas applied. Eight prompts precede separate worked answers; facilities transfer is retained. No learner citations, dates/revisions or teaching-method promises added.
