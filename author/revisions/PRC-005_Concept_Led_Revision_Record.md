## Changes and teaching decisions

The input comparison establishes changed department/manager/stage and unchanged worker classification before four result mechanisms. Mapped data, manager identity resolution, translated lifecycle access and automatic roles are connected in the normal case before partial delivery and independent variations.

Fictional person/employer/account/object IDs are removed. HR-Primary/Directory-Primary preserve necessary boundaries. Arbitrary workerNumber95005/identificationNumber95005 and the single-employee CompanyCore equality are replaced by independently mapped workerCategory Employee and CompanyCore testing that category. This retains the unchanged mapped-value/continuing-role purpose while removing the old deliberately artificial production criterion. It does not mark custom workerCategory as a built-in or infer stage from category.

Manager comparison still uses candidate identificationNumber, with M-OLD/M-NEW/M-MISSING as necessary account reference values rather than biographies or ISC object IDs. The account field is renamed managerReference to make its meaning explicit. Both intended candidates already exist with applied unique values; only one supplying profile/source, no competing manager fallback.

The manager section checks selected reference versus resolved identity; Preview is defined before relying on it. Provisioning meaning/support/permission conditions precede diagram use. Lifecycle uses an independent workerStage transform. Roles depend on identity criteria without converting that relationship into an unsafe peer transform assumption.

Two tables support changed inputs and combined intended results; two diagrams support dependency checks and exact membership reconciliation. No fixed lesson layout/word-count quota applied. All eight original question purposes precede worked reasoning; Leeds/Bristol AND-active transfer and continuing StaffPortal remain. Normal outcome is complete before manager null/unmatched variations.

Both [processing comparison](../../assets/PROCESSING_COMPARISON_GUIDE.txt) and [attribute tracing](../../assets/ATTRIBUTE_TRACING_GUIDE.txt) guides remain local2.0/published1.0 unchanged. No learner source/course links or presentation code added.
